# P23-TRN Sensitivity80 Report Template

No P23 model has been trained by this implementation task. Populate this report only from files generated by `scripts/run_p23_trn_nez_80.ps1`.

The P2 component score audit is diagnostic-only. Patient-oracle and true-count-assisted values are not deployable and must never be reported as formal P23 results.

P5 excludes causal evidence by design. P6 may be run only after `scripts/analyze_p2_component_scores.py` shows the causal admission criterion documented in the task request. P23 does not use V3, raw waveforms, true-K prediction, center-specific models, center-specific thresholds, or test labels for prediction.
