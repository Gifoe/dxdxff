# Remote Task 1 Omni raw baselines

Portable standalone baseline for the `upload-7-14` Task 1 data layout. It assumes:

```text
/root/autodl-tmp/raw/all_window_cache.pkl
/root/autodl-tmp/feature/all_window_cache.pkl
/root/autodl-tmp/csv/cohort_subjects.csv
/root/autodl-tmp/csv/fixed_outer_folds_v3_qbc.csv
/root/autodl-tmp/csv/outer_fold_ledger.csv
```

No repository patch and no EDF access are required. `run_baseline.py` reads the
raw cache directly and uses the supplied frozen 80-patient outer folds.

The upstream repository supplies reference *architectures*, not compatible
Task 1 checkpoints: SEEGNet is hard-coded around 1,000 Hz / 60 s input and
the CNN front end is also defined at that time scale.  This bundle therefore
implements adapted encoders and trains them from scratch on the frozen 80
patient Task 1 protocol.  Only CLAP and optional ImageNet ResNet-18 weights
are downloaded externally.  Do not install the whole `omni_ieeg` package:
its package metadata includes unrelated HFO, MNE, EDF, and dataset tooling.

```bash
cd /root/autodl-tmp/remote_task1_omni_baselines
bash scripts/install_requirements.sh
bash scripts/run_smoke.sh
```

The runnable baseline is a compact Omni-SEEGNet-style multiscale Conv1D +
BiLSTM + attention model trained from scratch, so it needs no external model
checkpoint. `prepare_checkpoints.sh` is retained only for later CLAP/ResNet
extensions.

The smoke run uses outer fold 1, reserves the next frozen fold group for
validation because `outer_fold_ledger.csv` contains only train/test rows,
selects the decision threshold on validation, and writes the held-out test
channel ledger plus a PyTorch checkpoint and provenance JSON.

The 80-patient cohort expands to 1,471,965 raw tokens: `[N,800] float32` alone is 4.39 GiB, in addition to the 6.35 GiB raw pickle. Full runs need at least 32 GiB host RAM unless token preprocessing is made streaming/memmap-backed.
