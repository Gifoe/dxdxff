# Name-bound feature mapping

The authoritative manifest, feature archive and name order are hash-pinned in `PROTOCOL_LOCK.json`. `FEATURE_TRIPLE_MAPPING.csv` is generated by matching **block=b0, physiological feature, aggregation, view**. No assumed offsets determine the mapping.

Fourteen triples: beta log-bandpower, low/high gamma log-bandpower, RMS, variance, line length/sec and spectral entropy, each with seizure mean/std. Each group has exactly one ABS, DELTA and RATIO main coordinate (42 effective coordinates). F0 retains62 of88 interface positions;12 retained positions are constant zero and8 are exact DELTA auxiliary duplicates. All26 ZDELTA positions remain masked.

The auxiliary DELTA positions for high gamma, line length/sec, RMS and variance, at both aggregation statistics, are updated by copying their corresponding modified main value. They have no independent correction coefficient. Protected constant-zero coordinates are not repaired or relabeled. Their missing numeric signal does not establish that delta/theta physiology is biologically useless.

Actual generation source is `neuroez_c/evidence_views.py` (SHA256201f888411a8f45fa363cfb2ac11c165a04ae2eef5abcd3aad64aedfe3098b03) and `task1_baselines/feature_aggregation.py` (SHA256426344bfa6ef0dd4b1dc59fe267d7920cef020fdcb42e834efc9a9ae6b4ca273). Window view formulas are ABS=x, DELTA=x−pre_mean, RATIO=log((abs(x)+1e-5)/(abs(pre_mean)+1e-5)). The pre-reference uses negative window centers, with the historical all-window fallback if no eligible pre-window exists. This source behavior is preserved, not used to make new measurements.

`p2_matched_simple` computes each seizure's finite-row window mean, then mean and population std of these per-seizure values across seizures for each canonical patient-channel. Averages occur **after** nonlinear RATIO construction. Window-level formulas do not imply exact linear relationships between final aggregated columns. Patient Z and the original FIT-only imputer/scaler further change coordinates. Ridge and COVE operate on these exact post-preprocessed tensors, before original LayerNorm; they do not operate on new windows or raw EEG.
