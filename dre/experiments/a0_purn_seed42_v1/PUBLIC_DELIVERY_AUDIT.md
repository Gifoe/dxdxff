# Public delivery boundary and evidence provenance

Only this new experiment directory is committed. Allowed content: executable
source/tests, architecture/protocol/hash metadata, audit/report Markdown and
anonymous aggregate CSV/JSON. No unrelated source or prior scientific result
is modified. Original feature archive, banks, checkpoints, patient/channel IDs,
individual arrays/predictions/labels, raw EEG and logs stay on the trusted server.

Public CSV rows are model, fold, center, fixed channel-count stratum, epoch,
normalization statistic, affine parameter distribution or aggregate contrast.
Feature mapping records name/index/main relationship, not clinical channel
identity. Public digests refer to original server files; no file contents or
patient lists are revealed by checkpoint/bank/prediction hash fields.
Global extrema/quantiles are the requested non-identifying statistic summaries,
not linked to a patient. Small center aggregates are disclosed as aggregates.

Private/binary/bytecode/log extensions are ignored. Scoped staged filename,
UTF-8/nonbinary, CSV identity/individual-score-column and credential-pattern
checks precede publication. Executed development source/tests/protocol match
PRETRAIN_AUDIT byte hashes; outer amendment/run/test match the separate frozen
outer dependency audit. LF Git normalization preserves executable/protocol
bytes. Aggregate result provenance hashes are server-artifact hashes, not
promises that every Git-normalized result text retains runtime CRLF bytes.

The original no-outer development lock and failed gate are retained as historical
stage facts. The user's later direct authorization is separately documented;
outer source is outside the original development code/test binding directories.
No silent gate relaxation, outcome-driven model change or second scientific
evaluation occurs. Independent verification only recomputes frozen metrics and
sampling intervals; it does not infer new scores or select new thresholds.

Original attachment and supplemental user text are represented by a request
digest/brief authorization record, not user-machine attachment paths or
credentials. No remote-access helper or connection secret is delivered.
GitHub tree parity against the reviewed local commit is checked after upload.
