# Implementation and leakage audit

- Base: original A1 patient-equal weighted BCE checkpoints from `codex/a1-a2-patient-equal-objective-seed42-v1`, 5 folds × 30 epochs. Source code, cache and frozen partition manifest are checked against hashes in `PROTOCOL_LOCK.json`.
- Source reproduction precedes probe training. All 150 saved A1 per-epoch validation grids and the five published VLOO fold scores were reconstructed exactly (`max_grid_error_vs_original=0`).
- `run_probe.py` builds only FIT and validation loaders. It never constructs an outer-test loader, computes outer predictions or reads outer performance results. The source cache/index constructor is shared with the historical A1 protocol; no outer labels are used in optimization, selection, diagnostics or gates.
- The entire A1 model is set to `requires_grad=False` and `eval()`. The pre-z embedding is the model's `patient_channel_embedding`; a read-only pre-hook captures the exact input to its final classifier as the relative contextual embedding. The classifier is checked to reconstruct the frozen A1 logits.
- Per-patient context uses only valid channels: embedding mean and `log(sqrt(population variance + 1e-5) + 1e-6)`. For each fold and base epoch, context mean/std are fit over FIT patients only, then applied unchanged to validation.
- P1 and P2 share one architecture, final-layer zero initialization, bounded `0.5*tanh` residual, parameter count, per-patient weighted BCE, AdamW schedule, 15 final epochs, full FIT-patient batch, and matched initialization/RNG. P1's context columns are all zero; P2 uses the normalized absolute context. At step 0 both exactly reproduce A1 logits.
- All 300 probe cells completed. The finalization audit verifies each P1/P2 pair has the same source-checkpoint digest, 15 probe epochs and state tensor shapes. Each head has 6,209 parameters (input 192, hidden 32). Only the final probe epoch is evaluated; validation never selects a probe epoch.
- VLOO selection reuses the original A1 30 base epochs, 19 fixed probability thresholds, 12-of-13 patient exclusion and original tie breaks. APPARENT_FULLVAL is reported separately. Label-using oracle/context correlations are diagnostic only.
- Patient-level representations, logits, labels, probe states, VLOO selections and runtime logs remain on the private server disk. Git contains only code, locks, aggregate tables, audits and report. No outer test was run.
