# Ictal Onset-Conditioned SSL + Patient-Relative, seed42 v1

**Status (2026-10-08): implementation and synthetic/unit tests available; real 80-patient training NOT run.** The original raw and feature caches are private server files, not included in the public GitHub repository or this package. An old audit verified alignment, but *independent EDF-to-cache seizure-onset provenance remains unverified*. Do not call this a completed clinical evaluation.

## Scientific question

Does learning an onset-conditioned representation from raw iEEG improve held-out-patient EZ localization **after** introducing a deterministic patient-relative coordinate? Does an explicitly relative cross-channel attention offer further incremental value?

Hypotheses:

- H1: `E1 > E0`, as PR is a useful inductive bias for raw features;
- H2: `E3 > E1`, proving SSL adds value conditional on PR;
- H3: if H2 passes a predeclared validation gate, `E4 > E3` tests *relative-difference attention*;
- H4: if H2 passes, `E3 > E5_SHAM` tests true onset pairing versus patient-internal sham pairings.

## Five arms and conditional controls

| Arm | Shared CNN | SSL pretrain | Patient PR | Attention | Status |
|---|---|---|---|---|---|
| E0 | same model | no | no | no | planned all folds |
| E1 | same model | no | yes | no | planned all folds |
| E2 | same model | yes, true onset pairs | no | no | planned all folds |
| E3 | same model | yes, true onset pairs | yes | no | planned all folds |
| E4 | same model | yes, true onset pairs | yes | explicit differences | only if E3-vs-E1 gate passes |
| E5_SHAM | same model | yes, shuffled pre/ictal pairs | yes | no | only if E3-vs-E1 gate passes |

R1/R2 terminology in past chats is different from the E0-E3 **variant names here**. E0–E3 form a factorial ablation. All four have **the same supervised head capacity**. E0/E1 start from the same fold seed; E2/E3 start from the same pretrained CNN encoder and the same head seed.

## Reuse of prior repo evidence

- RawTiny study: `https://github.com/Gifoe/dxdxff/tree/codex/rawtiny-patient-relative-seed42-v1`. Historical audit: 80 patients, 256 seizures, 7,635 unique channels, 24,995 run-channel incidences, 1,471,965 feature-aligned raw windows. Exact source hashes in `expected_sha.json`.
- B0 historical PR MLP: `https://github.com/Gifoe/dxdxff/tree/codex/omni-a1feature-complementarity-audit-seed42-v1/dre/experiments/calibrank_mlp_seed42_v1`. Patient Macro-F1 0.616167, EZ-AUPRC 0.531996, EZ-AUROC 0.726844, seed42.
- Ordinary patient Attention and raw-PR already tested and not proven useful over original A1. Relative-difference Attention is only a **conditional ablation**, not an assumed improvement.

## Data contract

The original raw cache is `[channel,15000]` at 250 Hz/60 s. The **legacy code** places event onset at its midpoint. Exporter crops:

- preictal: `[-15,-5)` s, corresponding to sample indices `[3750,6250)`;
- early ictal: `[0,10)` s, corresponding to sample indices `[7500,10000)`;
- each channel/seizure becomes `[2,2500]` in physical raw amplitude units.

No per-window standardization. Within each pair, the encoder normalizes both phases using the **same preictal mean/standard deviation**. This preserves within-channel changes in amplitude. Preictal or ictal regions overlapping padded/invalid raw data produce an **audit failure**, never silent imputation.

Only input signals, valid masks and labels are exported; no EDF filenames are encoded into model features, and no subject/center ID is passed to the model. Clinical channel labels in the cached `patient_index['labels']` follow **EZ=1 / NEZ=0**. The classifier's logit is **NEZ positive**. For evaluation, EZ score = `sigmoid(-logit)`.

For final benchmark, the original **80-person five-fold FIT/VAL/TEST assignment must be reused**, not regenerated by random KFold. The expected outer sizes are 16/16/17/15/16 and each validation split contains 13 patients. No change to patient inclusion criteria or center membership is allowed.

## Fixed predeclared attention/sham gate

Run E4 and E5_SHAM only when **validation** E3 - E1 shows mean patient Macro-F1 >= +0.020, EZ-AP nondecreasing, and at least 4/5 validation folds with a positive Macro-F1 difference. No test metric contributes to this gate. Test the optional attention model against E3, not only E0; test the true-pair SSL model against E5_SHAM to isolate onset pairing.

## Statistical/reporting rules

- Primary metric: mean across 80 patients of patient Macro-F1 (not pooled-channel F1).
- Secondary: mean patient EZ-AUPRC, AUROC when both classes occur, MRR and Top1.
- Report all five folds and centers; bootstrap paired **patients**, not raw windows, for 95% confidence intervals.
- A strong paper-quality claim additionally needs truly independent held-out patients/data, because this historic 80 cohort has been viewed and tuned on repeatedly. The script's outer estimates are exploratory.
- Historical B0 0.616167 and CDEL 0.644589 are context, **not** automatic per-patient paired comparisons without loading their exact aligned ledgers.
- Only a repeated test or external cohort after finalizing the design can establish patient Macro-F1 >=0.70; no method in this package assumes it can reach this number.
