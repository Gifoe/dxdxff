# R1 HLV ictal-dynamics, seed 42

This is a matched window-level R0/R1 comparison on the existing 80-patient, 7,635-channel Task-1 fixed five-fold fit/validation/test membership. R0 has the HLV branch off; R1 changes only the gated six-dimensional high-gamma, line-length and variance dynamics residual. Both retain patient-relative classification. `PROTOCOL_LOCK.json` was written before training; its first Git commit was pushed while R0 was running, after early R0 training/validation logs had begun. No protocol setting was changed in response to those logs.

**Result:** R0 validation patient Macro-F1 `0.650626`; R1 `0.651611` (delta `+0.000985`, 4/5 positive folds). EZ-F1 delta `+0.001070`, but EZ-AUPRC delta `-0.000196` and EZ-MRR delta `-0.019863`. The HLV gate activated (mean `0.02136`) and the mean gated-residual/base norm ratio was `0.02591`. R1 failed the required `+0.010` Macro-F1 improvement and ranking-improvement conditions. **No outer test was evaluated.** See `FINAL_REPORT.md` and `validation/VALIDATION_GATE.json`.

The source cache has 90 patients; the fixed-manifest allow-list selects exactly 80, with 256 seizure records. The private runner and checkpoints are on the original Windows server. Public files contain aggregate fold-level metrics only. Earlier outer outcomes on this same cohort were viewed in other experiments, so this retest is exploratory rather than an independent sealed confirmation.

For a same-server replay, set `R1_HLV_SOURCE_ROOT`, `R1_HLV_WINDOW_CACHE`, `R1_HLV_FIXED_MANIFEST` and `R1_HLV_RUNTIME` to the corresponding private locations. The published runner intentionally contains no private absolute cache/output paths. Run `code/run_matched.py --variant R0 --stage validation`, then R1, then `code/finalize_validation.py`. `code/evaluate_outer.py` refuses execution unless the gate JSON says `pass=true`; that condition is false for this experiment.
