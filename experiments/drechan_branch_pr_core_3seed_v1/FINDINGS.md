# 同一候选的核心模块诊断：实际三seed内部结果

## 结论与评估边界

**没有证据支持把当前新PR残差候选及其全部引导模块作为新主模型。** EarlyFiLM和正确早期生理对应关系未通过预设联合方向规则。LateGate与Raw发作前参考在三个seed的AUROC/Macro-F1方向均为正，但不能把方向一致等同于两项指标均有统计支持。删掉双引导的均值更好也不意味着可直接替换主模型。

这里的FULL是上一轮新增128个分支残差增益的候选，**不是历史Outer Macro-F1=0.653828的冻结主模型**。全部数值均来自原FIT内部TRAIN34–36/CAL8/ASSESS8、33名独立ASSESS患者、三个seed。内部B0原结构为0.619955，并非原Outer成绩降成0.62。原80人Outer记录保持不变，本轮无新Outer。所有结论均为历史队列上的探索性重复测试。

## 控制是否实际成立

六特征与两类PR、分支残差、直接生理输入、原CNN/池化/损失和完整患者更新均保留。移除EarlyFiLM或LateGate各减少1048参数，双删减少2096参数，因此删除差异同时包含容量与优化路径变化，不能全归因于生理信息。FULL/发作前参考删除/错配均为11553参数，单引导删除10505，双删9457。

错配只更换EarlyFiLM供体，保持同患者、同发作、完整有效支持一致，LateGate和直接输入仍正确。五折ASSESS每seed共766351次有效窗口出现均可在合法支持组内错配，singleton为0；该数包含重复患者出现，不是全队列唯一窗口总数。计数与实际Raw有效窗口经独立核验。完整覆盖的错配未明确变差，因此不能以“错配覆盖不足”解释阴性结果。

## 实际执行、交付与下一步边界

75次全新拟合、916完整epoch，加15个精确parentFULL复用（169历史epoch）。全部90个选择先回放/冻结，全部90组分数封存后统一统计。独立核验720行、6480项患者指标、全部区间及来源/覆盖，最大区间误差4.44e-16。匿名导出30个成员/29项有效载荷全部hash通过，本地无私有数据核验也通过。原始80人/7635通道/256次发作/1471965有效Raw窗口、原五折与seed协议未改；权重、逐例分数、身份、Raw、缓存及日志未上传。

固定parent资格与完整核心模块资格都为FAIL。**总体目标尚未完成，也不将这个诊断阶段缩小定义为成功。** 不因某个删除组均值较好就把它发布为新主模型；原0.653828Outer主模型继续保留。下一步应在另行冻结的同协议比较中去掉不获支持的新增残差/引导复杂度，重新检查两类PR及剩余部件，而不是继续叠加PR层或削弱无PR对照。最终80人Macro-F1>0.64、AUROC增益和保留模块的稳定贡献仍需真实完成与核验。
