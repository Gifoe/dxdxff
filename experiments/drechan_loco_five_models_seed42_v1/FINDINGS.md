# 四来源 LOCO：实际结果与解释

## 1. 完成范围与评价口径

五种固定配置，seed42，分别完整留出HUP36人、LZU21人、multicenter15人、pediatric8人。
共20个新训练单元，不复用旧五折权重、预处理、阈值或预测。80人、7,635唯一通道、256次发作及
1,471,965个有效Raw250通道窗口全部保留。16个神经网络单元实际完成201轮训练；SVM另有12个
FIT内患者隔离OOF子模型和4个概率校准器。所有跨患者拟合的预处理仅由相应FIT估计，包含每个OOF子折的单位尺度；
预测时的PR仅使用该患者自身完整通道的无标签统计，不拟合测试来源整体统计。

20个验证重放逐位一致后，全部模型、轮次和阈值冻结；20个测试预测全部封存后才统一计算指标。
独立核验通过400行患者结果、3,600项指标、405项名义区间和8项额外多重比较区间。
下述主结果均为80名患者等权平均，**不是通道pooled指标，也不是多seed平均或预测集成**。
EZ为报告正类。AP使用average precision；排名仅在每位患者内部计算，分数不取整、规范通道名用于并列排序。

主模型**不是每个来源都第一**。HUP的Macro-F1点值最高为SVM，LZU为Feature-only，pediatric为Raw-only。
相对我们自己的Raw-only，主模型在HUP、LZU、multicenter的Macro-F1和AUROC均提高，但在pediatric两项均略降。

pediatric只有8名患者，其结果精度有限，不以该来源的点值排名作强结论。

## 4. 配对不确定性：支持什么，不支持什么

对每个来源内部的患者进行10,000次seed42配对重采样，固定各来源人数、已训练模型和阈值。
区间条件于这四个来源与这些已训练模型，不覆盖重新训练、其他seed或新的医院抽样不确定性。
主要八项比较为四个Full-minus对照分别计算Macro-F1/AUROC；下表为Bonferroni校正区间。
差异单位为绝对百分点，正值有利于当前主模型。

| Full减去对照 | ΔMacro-F1及校正区间，pp | ΔAUROC及校正区间，pp |
|---|---:|---:|
| 我们的Raw-only |+3.03 [ +1.20, +4.93 ]|+4.23 [ +1.64, +7.21 ]|
| 我们的Feature-only |+1.37 [ −1.48, +4.21 ]|+0.13 [ −4.14, +4.64 ]|
| Linear SVM |+1.94 [ −1.02, +4.92 ]|+1.41 [ −2.81, +5.69 ]|
| 原始TimeConvCNN |+21.14 [ +16.31, +26.13 ]|+17.81 [ +10.18, +25.60 ]|

可支持的结论：在本次固定跨来源协议下，向我们自己的Raw-only方案增加当前生理输入及相应融合参数，
Macro-F1与AUROC的患者配对增量在八项校正后仍为正。这是**生理输入包相对Raw-only的条件预测增益**，
不是六项生理属性均有独立机制贡献的证明，也不是容量完全匹配的因果实验。

不支持的结论：不能认定Raw分支相对Feature-only已提供稳定增量；其Macro-F1、AUROC、AP、EZ-F1、
MRR和Top-1的名义配对区间均包含零。也不能认定当前主模型已明确优于线性SVM，主要两项比较区间包含零。
不得以当前主模型总体点值最高为由将其描述为所有来源、所有指标上的确定优势。

## 6. 比较与解释边界

- 六项为β、低γ、部分高γ80–125Hz、RMS、Line Length、Spectral Entropy10–125Hz。使用12个有效摘要坐标，
  保持原14槽输入并在相对统计前屏蔽Variance两个坐标。没有新增频带、提取数据或重做特征选择。
- 主模型保留Feature PR、Raw PR、自身发作前潜变量扣除及原0–8/8–20秒聚合；Early FiLM、Late Gate、
  Variance、Head Interaction始终删除。单分支沿用完整初始化的相应切片、64宽头及原缩放，不加宽补偿。
- TimeConvCNN是固定原始Raw无PR实现，保留约−29至+29秒全部有效窗口汇总、原BCE损失与BF16训练；
  我们的模型保留原分段／发作前参考、混合损失与FP32训练。各自验证和测试均FP32、TF32关闭。
  因而TimeConvCNN差距是**完整方案比较**，不能全部归因于CNN结构、显式特征或PR的某一个因素。
  不因它此次成绩较低而事后补调参数、换时间窗或重跑一个更有利的版本。
- 模型参数量：Raw+Feature9,329；Raw-only8,433；Feature-only1,025；TimeConvCNN11,336,737。
  单头宽度相同不等于参数容量完全相同。训练中存在共享GPU负载变化，训练秒数也不是受控的效率基准。
- multicenter/pediatric是来源分层，未核实为各自一家独立医院，故正式口径为“留一来源”。
  当前架构和六特征集合是在历史队列结果被反复查看之后确定；本轮仍是探索性跨来源评价，
  不是独立外部确认。一个seed不能建立seed稳健性，当前五组也不能证明六特征组合是全局最优。
- 本轮无测试后模型、阈值、特征、seed或来源筛选；固定主模型不因这些结果而更名。
  原始波形、身份、逐患者／通道预测、权重、预处理及日志均留在可信服务器。
