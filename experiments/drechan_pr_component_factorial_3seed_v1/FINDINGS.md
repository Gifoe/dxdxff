# 两类PR的独立贡献：实际内部三seed结果

## 结论

完整四格对照已完成。**Feature PR的内部证据较一致；Raw PR的平均AUROC/Macro-F1为正，但不确定性大，不能称为已证明稳定贡献。当前主模型和其历史Outer结果均不替换。**

本表是33名独立患者的原FIT内部ASSESS、三个seed平均，**不是新的80人Outer**。原主模型的历史Outer Macro-F1仍为0.653828。本轮FULL=0.619955来自较小内部TRAIN重新训练且评估对象不同，不能直接相减或称为主模型下降。

## 分开看PR，不将均值正向冒充统计证明

下表为FULL减单项删除，单位pp。名义区间来自10000次seed42唯一患者配对bootstrap；额外四项区间采用Bonferroni水平百分位尾部0.05/8，属于探索性近似。

| 条件贡献 | 指标 | 均值差 | 名义95%区间 | 额外四项区间 |
| --- | --- | ---: | --- | --- |
| Feature PR，保留Raw PR | AUROC | +1.499 | [+0.551,+2.615] | [+0.339,+2.966] |
| Feature PR，保留Raw PR | Macro-F1 | +1.806 | [+0.201,+3.642] | [-0.201,+4.297] |
| Raw PR，保留Feature PR | AUROC | +0.569 | [-3.342,+4.402] | [-4.426,+5.431] |
| Raw PR，保留Feature PR | Macro-F1 | +2.000 | [-1.027,+5.234] | [-1.870,+6.125] |

- Feature PR在3/3seed的AUROC与Macro-F1都正向；两项名义区间下限均大于0，但额外四项区间中的Macro-F1仍跨0。因此只能称内部证据较一致，不能宣称两项均已通过多重比较支持。
- Raw PR仅2/3seed两项同时正向；其AUROC和Macro-F1的名义区间都跨0，不能称稳定改善已获统计支持。
- Raw PR的平均EZ-F1反而为负贡献：FULL减w/o Raw PR约-1.207pp，区间[-6.710,+4.334]pp。NEZ-F1上升可以推高Macro-F1，不能说所有指标都提升。
- 全删PR相对完整模型的Macro-F1下降较大，但AUROC差的名义区间仍跨0。不能用该大F1差替代排序贡献证据。

## 交互与数值尺度

定义交互`FULL-WO_FEATURE_PR-WO_RAW_PR+WO_BOTH_PR`。Macro-F1交互为-9.326pp，名义区间[-14.528,-4.208]pp；AUROC交互为+0.137pp，区间[-4.279,+4.081]pp。这是本轮条件下的收益递减/重叠，不是“两个PR协同提高所有指标”的证据，也不代表生理因果机制。该交互不属于预先声明的四项主要区间族，不能忽略其探索性。

另一个真实但无标签的检查：最大TRAIN患者在初始化时，12000个Raw摘要坐标有Raw PR的平方和约12000、无Raw PR约0.30812，RMS比约197.35。该数值仅来自这一条工程入场检查，不是全队列平均，也不是分类结果。直接跳过Raw Z同时改变了输入尺度和优化状态，不能把删除后的下降全部解释为患者相对信息。

因此，下一轮固定测试一个保留原单头路径的非线性PR残差候选，并加入数值尺度合理、容量匹配且不使用其他通道的替代对照。该设计已在本轮评分前推送，不从本轮最好的删除组挑新主模型，也不修改本轮门槛或阈值。

## 完成范围与尚未完成的目标

45次全新拟合、621完整epoch；15个精确匹配内部B0复用。所有60个模型/预处理/轮次/阈值先冻结，全部60组分数封存后统一计算指标。服务器独立核验480行、4320指标、108名义区间和4额外区间，最大区间误差3.33e-16。全部结果见[主表](results/MAIN_RESULTS.csv)、[各seed](results/SEED_RESULTS.csv)、[五折](results/FOLD_RESULTS.csv)、[来源](results/SOURCE_RESULTS.csv)、[pooled](results/POOLED_RESULTS.csv)和[覆盖率](results/COVERAGE.csv)。

**本轮没有新主模型、没有新Outer，不能据此宣称完成“Macro-F1>0.64并改善AUROC”的总体目标。** 历史内部/Outer反复查看已造成研究选择暴露，新内部划分和三个seed不会消除它；所有结论均标记探索性重复测试。条件bootstrap不覆盖完整训练随机性或历史架构选择。原始波形、身份、逐例预测、权重、预处理、缓存和日志均未上传。
