# 中文研究结论

80人、7635通道全部纳入；每人100次无标签通道二分，双向评价。主效应（Global−Full CRPS）为 0.277503 [0.221522, 0.351705]。

相对于同来源背景的收益：0.279178 [0.204479, 0.384891]；EZ−NEZ相对偏离：0.958464 [-0.2508, 2.56101]；两者使用六项家族校正区间。

预先规定的完整机制链未全部成立，不能写成“证明PR机制”。应分别报告背景预测与EZ关联的证据。

Full相对仅中心化的额外收益：0.13979 [0.109881, 0.160299]。未显著不能解释为两者等价。

结论仅适用于该历史队列和预设探针。统计背景不等于健康基线；相对偏离关联不等于信息无损、因果机制或临床效能。之前PR未改善可迁移标准化分离度的结果保留。
