# 研究结论：PR的统计机制

80人全部评价，每人恰好一次，共7,635通道。79人在原FIT内留出；1名患者
在原五折中从未进入FIT，因此在计算结果前声明以其原validation路径评价，
不进入对应TRAIN/CAL。主分析保留80人，另报告预先声明的79人敏感性分析。

| 研究问题 | 真实计算结论 |
| --- | --- |
| 1. 是否存在可迁移的生理EZ/NEZ判别方向？ | 在本历史队列探针中有证据：Global的T=0.944，95% CI [0.747,1.150]，且高于训练标签置换参考范围。 |
| 2. PR是否提高对齐或标准化分离？ | 主探针对齐ΔA=+0.079，多重比较区间[0.022,0.142]；主终点ΔT=−0.069，95% CI [−0.136,0.001]，不支持提升。仅29/80人的T增加。 |
| 3. 收益来自居中、缩放还是两者？ | 居中不改变T/A，这是数学恒等；缩放产生主探针的角度变化。居中使中点MAE从1.330降至0.298，Full PR为0.264；Full相对仅居中的额外改善区间跨0。单独缩放反而放大漂移。 |
| 4. 主要影响排序几何还是共享决策坐标？ | 更明确的是坐标稳定化，不是新增排序信息。单坐标正仿射变换保持排名；Fisher探针对齐反而下降，不能称为普遍几何改善。中点不是已验证的临床阈值。 |
| 5. 正确患者参考是否优于匹配参考？ | 优于预设的同来源/通道数匹配donor，ΔT=+0.445，校正区间[0.169,0.758]；但donor造成巨大方差失真，不能据此证明生理特异性。 |
| 6. 哪些仍不确定？ | T提升、跨方向估计器一致的对齐收益、Full相对仅居中的增益、排除方差失真后的参考特异性，以及临床/新队列效果。 |
| 7. 能否据此把PR当作核心方法学贡献？ | 不能作为“提高可迁移判别信噪比”的核心证据。可以准确描述居中稳定坐标、缩放改变特定探针下的角度几何；本实验不证明新颖性、临床因果或不可替代性。 |

总体属于预设Outcome D：混合且依赖探针的结果。四来源T变化均为负，
方向对齐变化均为正；Fisher敏感性分析的对齐变化为负，全部保留。

9项测试、717,440个端点值、1,112个区间和25项多重比较区间通过独立核验。
