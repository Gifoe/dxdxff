# Preliminary Physiological Feature Analysis

We assessed the predictive information of the six physiological features using Logistic Regression in the original five patient-held-out folds. Regularization was selected by patient-isolated cross-validation within FIT, and CAL patients determined the classification threshold. Combining all six features with patient-relative normalization yielded patient-average AUROC 0.757 (95% CI 0.718–0.793), AP 0.554, Macro-F1 0.626 and Top-1 0.662 across 80 patients. Among the eight main configurations, the joint model had the highest AUROC and AP point estimates, whereas Line Length alone had higher Macro-F1 (0.631) and Top-1 (0.688). The four paired intervals against Line Length all included zero, so a joint-feature advantage over this single feature was not established. Compared with the globally standardized NoPR model, PR increased joint-model Macro-F1 by 14.40 percentage points (28-comparison-adjusted interval 7.51–21.53). The adjusted AUROC and AP differences spanned zero. Within-patient training-label permutations produced mean AUROC 0.487 across 100 repetitions. Together with the within-patient associations in Experiment A, these results support physiological feature information for cross-patient EZ localization without raw neural representations, but not the irreplaceability of each feature. This historical-cohort reanalysis provides exploratory evidence, not independent external validation.
