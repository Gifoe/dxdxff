# Six qualified record features: bounded conditional selection

The source and qualification audits produced six new temporal record-level
measurements, not evidence of predictive benefit. This study tests all64
subsets in four fixed contexts: physiology-only, original7, frozen Raw192,
and frozen Raw192+original7. The baseline physiology and new measurements
receive the same exact-constant-safe normalization. All choices remain in
the original FIT and20 inner partitions; each assessment's labels are absent
from the selector inputs. All choices and assessment scores are frozen before
the separate assessment-label evaluator runs.

This is an exhaustive low-dimensional ridge study, not full M8, not a new
independent cohort, and not a replacement for the earlier failed nonlinear
transfer result. No new encoders, extraction or Outer runs are authorized.
The six-family allocation gate and finite budget are in `PROTOCOL_LOCK.json`.

Server order: `prepare_inputs.py`; `select_and_seal.py select`;
`select_and_seal.py seal`; separate reporting and independent verification.
Private source paths are server-local and contain no credentials. Publish
only the whitelisted anonymous aggregates, never inputs, identities, heads,
per-channel predictions or logs.

## Actual outcome

All5120 choice fits and574 distinct assessment refits completed and replayed
exactly. The6-group continuation gate failed: no stable conditional increment
over Raw+original7 was established. See [REPORT.md](REPORT.md), `results/`
and `figures/`. No further full M8/Raw training or new Outer evaluation was
triggered by this screen. Earlier models and outcomes remain unchanged.
