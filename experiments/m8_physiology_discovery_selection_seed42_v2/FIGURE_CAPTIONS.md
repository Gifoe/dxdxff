# Figure captions and visual QA

All six figures use actual anonymous aggregates, fixed-order named features
and editable text. SVG/PDF,600 dpi PNG and compressed TIFF plus the plotted
source CSV are delivered at180 mm width. Static Python preflight passed14/14
checks. Each final PNG was opened and visually inspected: readable labels,
no clipped panels, correct zero references and uncertainty, no missing-result
interpolation. Vector exports come from the same figure object. This is not
a claim that every IEEE submission requirement has been independently audited.

1. **Within-patient physiological effects.** All32 groups and five phases in
   the primary unique51-patient FIT cohort. Color is the patient-mean signed
   rank-biserial effect (positive for EZ>NEZ). Dots mark the prospective
   BH/interval/patient/source/seizure reproducibility criterion, not predictor
   selection. Other overlapping FIT sets remain in the source table.
2. **Peri-onset trajectories.** Six measurements fixed before analysis, with
   pointwise95%10000-draw patient-bootstrap intervals. Display bins do not
   alter native masks. The zero-time line is cache-relative, not independent
   clinical onset. Bands are not simultaneous longitudinal hypothesis tests.
3. **Cardinality.** Fixed linear probes at1–9 groups (two coordinates each).
   Blue: nested-assessment mean/ID-cluster interval. Gray: five own-FIT means.
   Each k has255 appearances/79 identities. Intervals condition on selected
   paths; they do not rerun feature selection or represent neural Outer scores.
4. **Selection stability.** Frequencies across15 overlapping assessment paths,
   Jaccard and chance-adjusted overlap. The105 pairs/k are not independent
   replications. Frequency did not define a global Outer subset.
5. **Replacement/Raw increment.** Selected M8 minus eight registered references,
   six primary metrics, unadjusted95%10000-draw paired patient intervals. Raw20
   andRaw30 are both shown. Selected-versus-old7 adjusted intervals and all
   single-head comparisons, including positive ranking results, are tabulated.
   Historical architecture-different references are not mixed into this figure.
6. **Redundancy.** Label-blind primary FIT within-patient Spearman correlation,
   separately median-aggregated for mean/mean and SD/SD then averaged for display.
   Numbered columns match row/catalogue order. Constant coordinates are
   unavailable, not a reason to prune or a negative biological effect.

QA: sequential frequency palette, zero-centered effect/correlation palettes,
zero references for differences and patient-unit uncertainty. No synthetic
points, significance-star ranking, winner highlighting or unfavorable model
omission is used to manufacture a successful feature-discovery narrative.
