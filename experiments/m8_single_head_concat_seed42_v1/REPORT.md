# DREChannNet Single-Head Concat：完整五折结果

## 1. 结论

**`FAIL_STRICT_M8_TARGET`。** 内部验证预先锁定的候选为 **S4（Concat-6D + Gate）**。
相对原完整 M8，S4 的 AP、EZ-F1、MRR、Top-1 点估计提高，但 ACC、AUROC、Macro-F1、NEZ-F1 下降；四项主要分类指标也没有全部达到目标。
不能用排名改善、八项平均值或换选 S3 来替代本轮预先规定的八项逐项门槛。

**Independent D1 branch cannot yet be removed without verified performance loss.**

这句话的含义是“本次删除独立 D1 的方案未完成无损替代验证”，不是已经统计证明单头必然更差。
S4 对原 M8 的八项配对 95% 区间均跨零；没有预注册非劣界值、独立新测试队列或多 seed 证据，不能宣称统计非劣，也不能宣称所有单头方案均失败。
本轮 Outer 为 **`EXPLORATORY_REPEATED_TEST`**，不是盲测确认。没有观察本轮 Outer 后调参、改阈值、改候选或追加模型。

## 2. 实际运行、输入与公平性

- 完成 S0–S4 × 原五折 = **25 个从头训练单元、334 个 epoch**。历史五类参考只复用哈希核验的已封存 Outer 分数，不重新训练或对 Outer 做神经网络重预测。
- 每个新模型均覆盖同一 **80 位患者、7,635 个通道、256 次发作、1,471,965 个有效 Raw250 通道窗口**；没有采样、重新提取、择患者或择窗口。
- Raw 路径保留原 500 样本/2秒、24D CNN、同通道发作前 latent 扣除、0–8/8–20秒池化、可用发作 mean/population-SD、96D 全患者 Raw Z 和原始 masks。直接调用原 `DGMNet.features`。
- 生理输入仍为原七类 DELTA 测量，经原发作 mean/SD、Patient Z、FIT-only 缺失值处理及缩放得到 14D；不是 D1 hidden state 或 D1 logit。七类为 Beta、Low-Gamma、Partial High-Gamma、RMS、Variance、Line Length、Spectral Entropy。Partial High-Gamma 不冒充完整 80–150 Hz。
- 新模型只有 **110→64→1 GELU** 分类头，输出无界 NEZ logit；`p_EZ=1-sigmoid(logit_NEZ)`。无独立 D1、D1 预测残差、输出加权或第二决策头。
- S2/S4 在原预处理之后置零 Variance 的两个槽位（8、9）；窗口 DELTA 的 Variance group4 同步屏蔽。其余输入、Raw、通道映射和归一化不变。S0 的 14D concat 槽位全部置零。
- 保留原 FP32/TF32-off、AdamW(lr=0.0003, wd=0.001)、clip=1、最多30 epoch、最少停止 epoch6、patience6、每 FIT 患者一次等权更新、原患者顺序与原验证选择规则。
- 损失仍为原 **0.75 FIT-class-weighted NEZ BCE + 0.25 patient soft Macro-F1**。每折先依原验证 Macro-F1/EZ-F1/早 epoch 规则选 checkpoint 和 NEZ 阈值，再冻结。
- CNN/Gate 的初始化通过丢弃的未训练原构造器匹配原 RNG 消耗；不加载训练后的 D1 初始化到新模型。新头使用独立固定 seed 的默认 Linear 初始化，五臂配对一致。随机头而非原残差零输出初始化使 CNN 从首步即获梯度。

必须披露的非纯因果差异：原 M8 是预训练/冻结 D1 加 Raw 修正，新模型是端到端随机初始化的直接头；移除 D1 也移除了其分类器专属 LN88 readout。没有新增 LN110/14。头容量、有效输入权重数、优化几何和训练路径不同，因此不能把差异全部归因于“独立 D1 监督”。S0 的896个生理输入权重、S2/S4的128个屏蔽输入权重没有有效输入信号；参数接口匹配不等于有效信号容量完全相同。

### 核验结果

真实 FIT 梯度 admission、5项单元测试、25个验证分数重放（最大 logit 误差 **0**）均通过。
另对 **15 个已训练的 S0/S2/S4 折模型**在合法验证患者上扰动屏蔽输入，最大输出误差均为0；五折原 CNN/Gate 初始化逐一匹配。
Gate 末层在首个 smoke step 获非零梯度，受原零末层初始化影响的前层从后续 step 获非零梯度。丢弃的仅为每臂3步 FIT admission，未丢弃正式 epoch。

原始依赖、来源文档、输入角色、模型、阈值和评价程序均有绑定哈希。25个模型和候选先冻结，再封存 **80个 model-fold 分数单元**（25新主模型 +25历史参考 +30预先规定诊断），之后读取完整标签做汇总。主表10模型×80=800患者指标行，诊断另480行；验证8模型×65=520行。
服务器独立核验重算全部 **1,800行、369个配对指标区间、16个校正区间、216个绝对区间及每个区间全部10,000次抽样**，均 PASS。详见 `results/INDEPENDENT_VERIFICATION.json`。

最直接的容量匹配控制为Identity组S1/S2对S0：AUROC/EZ-F1有增量，且验证中也同向（S1−S0验证AUROC+0.031099、Macro-F1+0.014972）。S3/S4对S0还包含Gate变化，不是纯生理concat对比。生理信息同时改变错误权衡，例如S4−S0的NEZ-F1为−0.018718 [−0.043302,−0.003292]。

### 6.3 排序还是阈值分类损失？

不是纯粹阈值问题：S4 AUROC较原M8下降0.008714，说明全通道EZ/NEZ成对排序也损失；但AP、MRR、Top-1提高，说明“首个EZ靠前”与整体成对排序不等价。相对M8，Top-1有13位改善、6位变差、61位不变。
阈值错误权衡同时变化：S4的患者平均EZ比例偏差（预测EZ比例−真实比例）为−0.009238，原M8为−0.029065，S0为−0.062650。**有符号偏差更接近0不等于逐患者校准更好**，不能把Bias正差直接叫提升。
作为补充而非主分数，pooled计数从M8的TP747/TN5093/FP799/FN996，变为S4的TP762/TN4879/FP1013/FN981：少15个FN但多214个FP；这与NEZ-F1/ACC损失相符。计数不替代80人等权指标。没有使用Outer重新选择阈值。

## 9. 对整个方案的判断与下一步边界

1. **生理特征不是没有用。** 匹配Raw-only控制与固定模型置零诊断均支持其对受限Raw表示的预测增量，尤其AUROC/EZ-F1。但这不证明每个特征独立必要，也不证明7D是最优组合。
2. **直接concat并未无损替代双分支。** S4对原7D M8的4个点估计未达标，对同6D M8的Macro-F1/EZ-F1差距更大。现有严格交付标准下不能将其作为等效替代。
3. **不能把失败归为单一原因。** Raw表征没有被完全破坏（仍有排序及检索信号），生理输入有作用（屏蔽后变差），Gate贡献小且指标不一致；这些没有充分隔离融合能力、readout尺度/LN88、随机端到端优化与D1预训练锚定各自的因果作用。最终损失代数相同，不意味着优化路径相同。独立D1提供稳定生理锚点是合理假说，尚非已证明机制。
4. **不在这份Outer上继续找救场配置。** 本任务到固定矩阵的真实训练、一次冻结评价、诊断和上传结束。保留原M8作为当前“八项不可退化”目标的参考；如以后另立任务，应预先固定只改变一个训练/读出因素的控制，并使用合法内部验证及未适配的新数据验证。这里没有运行或宣称新的改进实验。
